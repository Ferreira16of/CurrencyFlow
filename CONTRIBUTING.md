# Contributing to CurrencyFlow

Thanks for considering a contribution!

1. Search existing issues before opening a new one.
2. For major changes, open an issue first to discuss the proposal.
3. Keep pull requests focused and explain the reason for each change.
4. Never commit API keys, tokens, credentials, or personal information.
5. Do not invent historical exchange-rate data or describe reference rates as guaranteed market prices.
6. Test conversion, currency swapping, historical queries, responsive layouts, and error states in a browser.
7. Update documentation when behavior or data sources change.

## Pull requests
Include a clear summary, motivation, and manual test steps. Keep HTML semantic and JavaScript dependency-light. All contributors are expected to follow the Code of Conduct.

## Local development
No build step is required. Open `index.html` or use VS Code Live Server.
